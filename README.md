# CheekyPanda

Premium luxury photography catalogue website for CheekyPanda Photography, designed for WhatsApp sharing and quick PDF export.

## Project structure
- `index.html` – main landing/catalogue page.
- `styles.css` – premium dark-gold visual system and animations.
- `script.js` – hover tilt, click highlight, and reveal animations.
- `assets/` – logo and banner assets.

## Run locally
```bash
python -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Export to PDF
1. Open the site in Chrome.
2. Press `Ctrl+P`.
3. Choose **Save as PDF**.
4. Enable **Background graphics**.
